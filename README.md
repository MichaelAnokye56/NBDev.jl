# NBJulia

[![Build Status](https://github.com/MichaelAnokye56/NBJulia.jl/actions/workflows/CI.yml/badge.svg?branch=main)](https://github.com/MichaelAnokye56/NBJulia.jl/actions/workflows/CI.yml?query=branch%3Amain)
[![Coverage](https://codecov.io/gh/MichaelAnokye56/NBJulia.jl/branch/main/graph/badge.svg)](https://codecov.io/gh/MichaelAnokye56/NBJulia.jl)

Notebook-driven development for Julia — modeled on Jeremy Howard's
[nbdev](https://nbdev.fast.ai). Write code, tests, and docs together in a
notebook under `nbs/`; export the code to a real package in `src/`; generate
a documentation site; run the notebooks themselves as tests.

**Status**: early scaffold. This file will become auto-generated from
`nbs/index.ipynb` once the docs pipeline exists (see `nbs/index.ipynb` for
the real project description in the meantime, and
[`ReverseEngineered/nbdev_files/`](../ReverseEngineered/nbdev_files/) for the
nbdev reverse-engineering notes and implementation plan this package is
being built from).
